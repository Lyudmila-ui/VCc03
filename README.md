# Разработка SEO-ядра

Псевдоагент на FastAPI и ChatGPT. По ссылке он просит модель составить план из 5–6 шагов, выполняет каждый шаг и собирает из ответов SEO-ядро.

Если у модели нет доступа в интернет, сервис сам скачивает страницу и подставляет её текст в промпты.

## Запуск

1. Впишите ключ в `.env` (`OPENAI_API_KEY`).
2. Из корня проекта:

```bash
docker compose up --build
```

3. Откройте http://localhost:8080

`OPENAI_HAS_INTERNET`:

- `auto` — один пробный запрос с поиском. Если поиск недоступен, страница скачивается локально.
- `true` — в шаги уходит только ссылка.
- `false` — всегда скачивается HTML, модели уходит текст страницы.
