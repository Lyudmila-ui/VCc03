# Разработка SEO-ядра

Псевдоагент на FastAPI и DeepSeek. По ссылке он просит модель составить план из 5–6 шагов, выполняет каждый шаг и собирает из ответов SEO-ядро.

DeepSeek не открывает ссылку сам, поэтому сервис скачивает страницу и подставляет её текст в промпты.

## Запуск

1. Откройте файл `.env` в корне проекта.
2. Вставьте ключ в строку `DEEPSEEK_API_KEY`. Ключ берётся на https://platform.deepseek.com/api_keys
3. Из корня проекта:

```bash
docker compose up --build
```

4. Откройте http://localhost:8080

Модель по умолчанию — `deepseek-flash`. Другую можно указать в `DEEPSEEK_MODEL`, например `deepseek-v4-pro`.
